Anatomy of a Dockerfile

The factory blueprint for your application's shipping container

# 1. Base Image (The Foundation) FROM node:18-alpine # 2. Working Directory (The Workspace) WORKDIR /app # 3. Dependencies (Install packages) COPY package*.json ./ RUN npm install # 4. Source Code (Copy project files) COPY . . # 5. Port Exposure (Open a window) EXPOSE 3000 # 6. Start Command (Engine ignition) CMD ["npm", "start"]

Line-by-Line Breakdown

FROM node:18-alpine

The Foundation: Every container needs a starting point. This tells Docker to start with a lightweight Linux image that already has Node.js version 18 installed.

WORKDIR /app

The Workspace: Sets the active directory inside the container box (like typing cd /app) so all future commands happen here.

COPY package*.json ./ & RUN npm install

The Dependencies: Copies your package lists into the container and runs the installer to download all necessary libraries in isolation.

COPY . .

The Source Code: Takes the rest of your local project files (JS, CSS, HTML) and moves them into the container's workspace.

EXPOSE 3000

The Port: Opens a specific port on the container so the outside world can talk to the application running inside.

CMD ["npm", "start"]

The Start Command: The final instruction that runs automatically the exact second the container spins up.

How to Build & Run Your Container

# 1. Build the Docker Image (tag it as 'my-node-app') docker build -t my-node-app . # 2. Run the Docker Container (map port 3000 on host to 3000 in container) docker run -d -p 3000:3000 --name my-running-app my-node-app

docker build -t my-node-app .

Building the Image: Reads the Dockerfile in your current directory (.), executes every instruction step-by-step, and packages the result into a reusable image tagged as my-node-app.

docker run -d -p 3000:3000 --name my-running-app my-node-app

Running the Container: Spins up an active container instance from your image. The -d flag runs it in the background (detached), and -p 3000:3000 forwards port 3000 from your computer into the container so you can view your app in a browser.

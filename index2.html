Git Essential Cheat Sheet

Your command-line roadmap for version control and team collaboration

# Typical Git Lifecycle git init # 1. Initialize local repository git status # 2. Check changed files git add . # 3. Stage changes for commit git commit -m "msg" # 4. Save snapshot with a message git push origin main # 5. Send commits to remote repository

Setup & Initialization

git init

Initialize: Turns your current working folder into a brand new, empty Git repository, enabling version tracking.

git clone <url>

Clone: Downloads an existing remote repository (from GitHub, GitLab, etc.) onto your local machine along with its entire history.

Basic Daily Workflow

git status

Inspect State: Displays paths that have changes, which files are staged for commit, and which are untracked.

git add <file> (or . )

Stage Changes: Moves modified or new files from your working directory into the staging area, preparing them for a snapshot.

git commit -m "commit message"

Save Snapshot: Takes all staged changes and permanently records them into the local repository history with a descriptive log message.

Branching & Navigation

git branch

List Branches: Shows all local branches in your repository and highlights the one you are currently working on.

git checkout -b <branch-name>

Create & Switch: Creates a brand new feature branch and immediately switches your workspace over to it.

Remote Collaboration

git push origin <branch>

Upload: Sends your committed local history changes up to the specified remote server branch so others can access them.

git pull

Fetch & Merge: Downloads the latest updates from the remote server repository and automatically merges them into your active local branch.
